Datas e fontes

As aplicações usam a data original de publicação; palestras e patentes, as datas registadas. Datas sem hora correspondem à meia-noite na Coreia. Não se inventam horas para registos só com ano. Os registos sem data ficam no fim. A reconstrução não altera IDs nem datas.

A fonte original das palestras e pesquisas é bhban.kr. Consulte as indicações de publicação e pré-publicação, citações e ligações originais. A API pública não altera as condições de utilização dos documentos.

Todos os ficheiros são atualizados na geração do site. Conforme o alojamento, JSON Feed pode usar application/json, permitido pelo JSON Feed 1.1.
